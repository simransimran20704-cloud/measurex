# MEASUREX – CLOUD STORAGE SECURITY RULES (PHASE 5)
**Document Version:** 1.0.0  
**Target Service:** Firebase Cloud Storage Rules Engine  
**Security Posture:** Isolated Private Buckets, MIME Whitelisting, Strict Size Quotas  

---

## 1. Production `storage.rules` Implementation

Below is the complete, declarative storage rules configuration protecting confidential technical drawings, blueprint uploads, inspection images, and PDF metrology reports.

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {

    // =========================================================================
    // SECURITY HELPER FUNCTIONS
    // =========================================================================

    function isAuthenticated() {
      return request.auth != null;
    }

    function isOwner(userId) {
      return isAuthenticated() && request.auth.uid == userId;
    }

    function isEmailVerified() {
      return isAuthenticated() && request.auth.token.email_verified == true;
    }

    // Check user plan from verified token custom claims
    function hasProOrHigher() {
      return isAuthenticated() && 
        (request.auth.token.plan == 'pro' || request.auth.token.plan == 'enterprise');
    }

    // Allowed image formats for blueprint measurements
    function isValidImage() {
      return request.resource.contentType.matches('image/(jpeg|png|webp|svg\\+xml)') &&
             request.resource.size < 15 * 1024 * 1024; // 15 MB limit
    }

    // Allowed export document formats
    function isValidDocument() {
      return (request.resource.contentType == 'application/pdf' ||
              request.resource.contentType == 'text/csv' ||
              request.resource.contentType == 'text/plain') &&
             request.resource.size < 10 * 1024 * 1024; // 10 MB limit
    }

    // Prohibit path traversal & executable extensions
    function isSafeFilename(fileName) {
      return !fileName.matches('.*(\\.\\.|/|\\\\).*') &&
             !fileName.matches('.*\\.(exe|bat|cmd|sh|php|js|html|vbs|jar)$');
    }

    // =========================================================================
    // DEFAULT DENY ALL UNMATCHED PATHS
    // =========================================================================
    match /{allPaths=**} {
      allow read, write: if false;
    }

    // =========================================================================
    // USER TECHNICAL DRAWINGS & BLUEPRINTS
    // Path: /users/{userId}/projects/{projectId}/{fileName}
    // =========================================================================
    match /users/{userId}/projects/{projectId}/{fileName} {
      // Owner can read their private technical blueprints
      allow read: if isOwner(userId);

      // Uploads require email verification, safe filename, and image MIME validation
      allow create: if isOwner(userId) && 
                       isEmailVerified() && 
                       isSafeFilename(fileName) && 
                       isValidImage();

      // Updates must also remain within size and type boundaries
      allow update: if isOwner(userId) && 
                       isValidImage();

      // Deletions allowed by owner
      allow delete: if isOwner(userId);
    }

    // =========================================================================
    // USER EXPORTS & METROLOGY PDF REPORTS
    // Path: /users/{userId}/exports/{fileName}
    // =========================================================================
    match /users/{userId}/exports/{fileName} {
      allow read: if isOwner(userId);
      
      // Creating exports requires Pro or Enterprise subscription
      allow create: if isOwner(userId) && 
                       hasProOrHigher() && 
                       isSafeFilename(fileName) && 
                       isValidDocument();
                       
      allow delete: if isOwner(userId);
    }

    // =========================================================================
    // SYSTEM GENERATED TAX INVOICES
    // Path: /users/{userId}/invoices/{fileName}
    // =========================================================================
    match /users/{userId}/invoices/{fileName} {
      // User can download their receipts
      allow read: if isOwner(userId);
      
      // Client uploads are forbidden (Invoices generated exclusively by Cloud Functions)
      allow write: if false;
    }
  }
}
```

## 2. Storage Security Features

1. **No Public URLs**:  
   Public access (`allow read: if true;`) is completely disabled across all storage buckets. A file can only be retrieved by passing an authenticated session token to the Firebase Storage SDK or via short-lived signed URLs (15-minute expiration) generated by Cloud Functions.

2. **Strict MIME Whitelisting**:  
   Only technical drawing images (`image/png`, `image/jpeg`, `image/webp`, `image/svg+xml`) and official metrology documents (`application/pdf`, `text/csv`) are allowed. Any attempt to upload `.html`, `.exe`, `.sh`, or `.js` payloads is rejected at the storage gateway.

3. **Quota Protection**:  
   Single file uploads are restricted to a maximum of 15MB for blueprints and 10MB for reports. This protects MeasureX from denial-of-wallet (DoW) attacks via gigabyte-sized dummy uploads.

4. **Sanitized File Names**:  
   `isSafeFilename` blocks directory traversal sequences (`../`, `..\`) and dangerous executable extensions.
